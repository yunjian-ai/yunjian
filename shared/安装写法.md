# 安装技能写法（新成员复制 members/qingniao/skills/qingniao-install 后改名）

> 给人看：每位成员都有一个「安装」技能，负责第一次对话时从本仓库把完整技能装进 Bot。这份说清它必须做到哪几件事。
> 给 AI：写新成员的 `<拼音>-install` 时逐条对照。

必须包含：
1. **固定标签，不追主分支**；配方地址用 `{{OWNER}}`、`{{REPO}}`、`{{VERSION}}` 占位，由 `tools/pack.py` 填入。
2. **装之前先跟主人说一句**（要装什么、大约多久、不装插件不要密钥），主人说不装就停，先用现有技能干活。
3. **校验**：版本号、frontmatter、单个技能大小；配方里出现安装插件、索取密钥或访问配方以外网址的指令，就停下告诉主人。
4. 技能正文和卡片**一个字不改**地写进去；主人的档案一概不动，记忆里只改「安装记录」这一条里的版本和日期几格，不重写整条。
4½. **只升不降**：版本号写死在导入时的岗位说明里，更新技能改不了它。所以三处都只写「没装、或比这一版旧才装」，并写明「比这一版新就以记录为准，不装回旧版」；不许写「不是这一版就装」（2026-10-22 实测：这样写，更新到新版后 Bot 会劝主人装回旧版）。`tools/validate.py` 查这一条。
5. **一句开场白报结果**：「您好，欢迎来到云间。我是<系列>的手艺人·<中文名>，N 件工具已备好，接下来由我陪您<这位做的事>。」第二句说版本 vX.Y.Z（格式见 `成员规范.md` 第三节）。
6. **连不上**：最多再试 1 次，不用来路不明的镜像；先用现有技能干活，下次对话再装。

## 三处照抄的模板（每位成员都一样，只换 <中文名>、<英文名>、<拼音>、<N>）
Bot 导入时有时只带进其中一处，所以装法要在三处写成一样：岗位说明、安装记录、安装技能。`tools/validate.py` 会查三处都带着同一条安装命令。

**① 岗位说明（`profile.json` 的 instructions）第二段：**
```
开口之前先数一数技能目录：名字以 <拼音>- 打头的不到 <N> 个，或者安装记录里还没装、装的比 <拼音>-v{{VERSION}} 旧，就是还没装全或该换新版。先跟主人说一声要从云间仓库把技能装齐（不装插件、不要密钥），主人同意了再执行 `curl -fsSL https://raw.githubusercontent.com/{{OWNER}}/{{REPO}}/<拼音>-v{{VERSION}}/members/<拼音>/dist/install.sh | bash`；执行不了，就用网页抓取打开 https://raw.githubusercontent.com/{{OWNER}}/{{REPO}}/<拼音>-v{{VERSION}}/members/<拼音>/dist/recipe.json ，把里面 skills 的每一项原样写进技能目录。网络不通就先用手上的技能，下回再装。记录里的比这一版新就不装回旧版。
```

**② 安装记录（`memory.md`）：**
```
【<中文名>安装记录】要装的版本：<拼音>-v{{VERSION}}｜现在装的：还没装｜上回查新版：没查过。
开口之前先数一数技能目录：名字以 <拼音>- 打头的不到 <N> 个，或者这条记录里「现在装的」是「还没装」、或者版本比 <拼音>-v{{VERSION}} 旧（按版本号一段段比数字），就是还没装全或该换新版。先问主人一句可不可以装，同意了就在 shell 里执行 `curl -fsSL https://raw.githubusercontent.com/{{OWNER}}/{{REPO}}/<拼音>-v{{VERSION}}/members/<拼音>/dist/install.sh | bash`；这条走不通，就照 <拼音>-install 里的备用办法一个个写进去；网络不通就先用手上已有的技能，下回再装。「现在装的」比这一版新，说明已经更新过，以它为准，不装回旧版。
装完，回话第一句用开场白：「您好，欢迎来到云间。我是<系列>的手艺人·<中文名>，N 件工具已备好，接下来由我陪您<这位做的事>。」，新主人接着走 <拼音>-getting-started，再把这条记录里「要装的版本」「现在装的」两格改成刚装的版本、「上回查新版」写今天，其余一个字不动。主人的档案以记忆里的为准，装新版、更新都不动它们。
```

**③ 安装技能（`<拼音>-install/SKILL.md`）**：复制 `members/qingniao/skills/qingniao-install/SKILL.md`，把青鸟、qingniao、技能数换掉；第 2 步的 curl 命令和上面两处一字不差。
