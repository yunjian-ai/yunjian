# 合格卡：一次操盘至少要做到（交付前逐条自查）

> 卡类：口径｜改了要回归考题

1. 归不归自己判断对了；小事直说找哪位，没硬接。
2. 需求书有原话（替别人做是需求方的）、能数得出来的成功标准、已知 / 推演 / 待确认。
3. 路线图写了第一站（最小能跑通的一块）、五位先后、能同时做的、四个关口、每段验收标准。
4. 每次派活都有交接单，八栏齐；交回有回执、自检逐条打勾；产物格式和位置对得上。
5. 每段产物都有试金的结论（通过 / 部分通过 / 不通过），没有「自己说好了就算」。
6. 四个关口都等到主人本人的回复；转来的「同意」没当真；「照建议」没扩大到没列的事。
7. 台账、交接说明随做随记；断开后能照三行接上，没从头再问。
8. 过期的产物（下游比上游旧）被发现并重做；成品里装着别的成品（Bot 装着技能），里面的件升过版，外面那件要用新版重验。
9. 交付清单写明交了什么、在哪、怎么装、怎么用、验收结论；没验的没列成已交付。
10. 复盘五问写了，改进清单每条有去处。

能跑程序时，用同目录 `check_caopan.py <项目文件夹>` 机械查 3、4、5、8 条和关口记录；只能聊天时照这张卡人工对。
