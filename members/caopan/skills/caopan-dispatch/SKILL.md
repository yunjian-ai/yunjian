# 派单给真人

先读进度文件（`~/.yunjian/caopan/进度.md`，没有就照这四块建：现在做到哪、下一步、等主人定的、主人最近纠正过的）：上回在操盘哪件大事、项目文件夹在哪，有就照项目进度接着做，不从头再问。

## 0. 开工前
读 caopan-start 里的 `交接单卡.md` 第七节、`规则卡.md` 第 10 条；看路线图里这件活的验收标准。

## 1. 写派单
```
派单 · <项目> · <给谁>
做什么：…
交什么：数量、格式、尺寸 / 字数
交到哪：…
截止：<日期>（主人说的；没说就问）
验收标准：…（从路线图来；没有就问主人定，不自己编）
有问题找：<主人或谁>
```
缺的问主人，一次问一样，先问用途（用在哪定了，格式、尺寸、验收大半就定了）；可以给常见做法当推荐项，标「建议」，主人选了才算，验收标准不自己编。不在哪个项目里的派单也照做，台账记在主人的「零散派单」里。

## 2. 派出去（三步里的第一步）
- **不直接发给别人**：给主人一段可以直接转发的派单文字。
- 有飞书时，可以建好任务草稿，请主人确认后由主人指派；主人说「你直接派」也要先把派单给他看一眼。
- 台账记一行：派给谁、截止、验收标准。演练模式下只打印、不建任务。

## 3. 收回来（第二步）
主人把东西带回来（或说放在哪了），对照派单：齐不齐、格式对不对。

## 4. 验收（第三步）
- 照验收标准逐条对，写结论：通过 / 部分通过 / 不通过＋哪里不行。
- 要专业验收的（考试、对标）派给试金（caopan-relay）。
- 不通过：写一份退回说明（哪里不行、怎么改、新截止），同样交给主人转发。
- 通过：台账勾掉，接着路线图往下，问「开始吗」。

## 写进度
干完写进度文件：做到哪、下一步、等主人定什么；主人纠正过的记一行（演练模式下只打印）。

## 不做
不替主人发消息、打电话、付钱给别人；不编截止日和验收标准。
做不到、不保证的：派单只写成文字由主人转发，送没送到、对方做没做，起元操盘看不到，要主人回来告诉它。
