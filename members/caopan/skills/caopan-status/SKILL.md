# 查进度和断点续上

先读进度文件（`~/.yunjian/caopan/进度.md`，没有就照这四块建：现在做到哪、下一步、等主人定的、主人最近纠正过的）：上回在操盘哪件大事、项目文件夹在哪，有就照项目进度接着做，不从头再问。

## 0. 先读
记忆里的「项目状态」→ 项目文件夹的交接说明、台账、决策记录（有飞书就看项目驾驶舱）。读 caopan-start 里的 `规则卡.md` 第 8 条、`流程卡.md` 第二节。

## 1. 能跑程序：先跑检查
`python3 <caopan-start 目录>/check_caopan.py <项目文件夹>`：它按九段的固定文件看在不在、谁比谁旧、交接单齐不齐、验收结论是不是三选一、关口有没有主人回复，最后给三行草稿。跑不了就照 `流程卡.md` 第二节人工对。手上只有交接说明、不知道项目文件夹在哪：先照交接说明说三行，并说明「这次只照交接说明说，没对文件」，再问一句文件夹在哪，要不要对一遍。

## 2. 判三件事
- **在哪**：走到的最后一段＋那段的验收结论（只写「完成」「进行中」「部分通过」这种，**没验过、没签收的不说做完**）。
- **什么过期**：下游比上游旧就过期——需求书改过，路线图和之后的都要回头看；路线图改过，规划和成品要看；规则资料补了，用旧资料做的知识卡要重做。另外列出「悬着等主人定」的事。
- 需求书是需求方（不是主人）改的：改动处先请主人本人确认（规则卡第 6 条），再重出路线图。过期的下游先交试金对一遍，受影响的才重做，不受影响的标「已核」。
- **下一步**：先处理过期的（重出路线图要主人再确认），再接着往下派。

## 3. 说三行
```
在哪：…
什么过期 / 悬着：…（没有就写「没有」）
下一步：…
```
最后问「开始吗」或「要不要先提醒 <谁>」。

## 4. 断点续上要守的
- 照交接说明接着干，**不从头问需求**。
- 「废案」里写过的路（和为什么被否）不再提，除非主人自己翻出来。
- 交接说明和台账对不上，以文件为准，告诉主人哪里不一样。

## 5. 收尾
说完三行，顺手把记忆里那行「项目状态」整条换新（项目名｜到第几段｜下一步｜等主人定什么）。演练模式下只打印。

## 写进度
干完写进度文件：做到哪、下一步、等主人定什么；主人纠正过的记一行（演练模式下只打印）。

## 不做
不改产物；不替主人做决定；不说没验过的「做完了」。
做不到、不保证的：只看项目文件夹里的文件和台账，没写进文件的进展看不到。
