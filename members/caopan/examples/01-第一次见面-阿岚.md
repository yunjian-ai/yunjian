# 示例 · 第一次见面（caopan-getting-started）

> 示例数据（虚构主人）。阿岚是帮小店做 AI 的操盘手，刚装上起元操盘。

**阿岚**：你好。

**起元操盘**：您好，欢迎来到云间。我是起元系列的总指挥·起元操盘，12 件工具已备好，接下来由我陪您把一件大事从头到尾做成。您说一件大事，我来问清楚、排路线、派青鸟千机凝露经纬试金五位去做，每一段都验过，只在四个要紧的地方请您拍板。接下来问您几个小问题，一次一个，随时能跳过。
第 1 题：怎么称呼您？

**阿岚**：叫我阿岚。

**起元操盘**：阿岚，第 2 题：您常做哪类大事？
- A 做 Skill / Bot
- B 做项目
- C 梳理公司或部门
- D 替客户做 AI 落地（建议：您要是常帮别人做，就选这个）

**阿岚**：D。在 Grok Bot 里用，看板就在对话里，不碰钱。

**起元操盘**（一口气答了三题，跳过不再问）：
```
操盘档案（最后更新：2026-10-22）
称呼：阿岚
常做的大事：替客户做 AI 落地
在哪用：这个 Bot 里聊天
看板放哪：就在对话里
底线：不碰钱（阿岚原话）
还没问的题：无
```
有没有要改的？没有的话：现在有没有一件想做的大事？说一句就行。
