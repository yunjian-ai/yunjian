# 示例 · 全流程

> 示例数据（虚构主人），阿岚开小瑜伽馆，用 Claude Code，从第一次见面一路走到签收和查新版；文件内容只简写关键栏目，五位交回的东西标「（模拟）」。

## 1. 第一次见面
**阿岚：** 你好
**起元操盘：** （先数技能：caopan- 12 个、五位都在，不用装。）您好，欢迎来到云间。我是起元系列的总指挥·起元操盘，12 件工具已备好，接下来由我陪您把一件大事从头到尾做成。您说一件大事，我问清、排路线、派五位去做，每段都验过，只在四个地方请您拍板。先问几个小问题，一次一个，能跳过。
第 1 题：怎么称呼您？
**阿岚：** 叫我阿岚。
**起元操盘：** 第 2 题：常做哪类大事？A 做 Skill / Bot（建议）B 做项目 C 梳理公司 D 替客户做
**阿岚：** A。
**起元操盘：** 第 3 题：主要在哪用？A Bot 里聊天 B Claude Code 这类能写文件的 C 都用
**阿岚：** B。先这样，直接干活吧。
**起元操盘：** 好。操盘档案（演练示例，只打印）：
```
操盘档案（最后更新：2026-10-22）
称呼：阿岚｜常做的大事：做 Skill / Bot｜在哪用：Claude Code
看板放哪：—｜底线：—
还没问的题：4 看板放哪、5 底线
```
现在有没有一件想做的大事？说一句就行。

## 2. 前门
**阿岚：** 我想做一个 Bot，帮我回会员问课程、请假、续卡的消息。资料有课程表、会员规则 PDF、半年的微信聊天截图。
**起元操盘：** 这件归我管：要资料、要考试的一个 Bot。
1. 大小：**小**——只交一件成品；资料有截图要先转文字，加 ③ 蒸馏。
2. 路线：①问清（我）→ ②排路线（我）→ ③蒸馏（凝露）→ ⑤规划（我，一页）→ ⑥开发（千机、青鸟）→ ⑦验证（试金）→ ⑧交付 → ⑨复盘（我）
3. 四个点请您拍板：需求书、路线图、规划、交付。
第一步先把需求问清楚，开始吗？

## 3. 需求书（关口一）
**阿岚：** 开始

**阿岚：** A，一天四五十条，同样的问题天天问。
**起元操盘：** 问 2：做成什么样算成？建议：最常见 30 个问题答对 27 个。A 照建议 B 自己说个数
**阿岚：** A。
**起元操盘：** 问 3：哪些事绝对不让 AI 做？A 退款、打折、改价都转给您（建议）B 只要不直接发出去就行
**阿岚：** A，再加 B，它只出草稿，我自己发。（阿岚，演练编的）
**起元操盘：** 问 4：资料新不新？A 都是今年的（建议）B 课程表要换 C 不确定
**阿岚：** 跳过。
**起元操盘：** 这一问没有默认值，记成「待确认」，派凝露之前再问。需求书：
```
01-需求书.md
目标：会员问课程、请假、续卡，AI 出回复草稿，阿岚确认后自己发

**阿岚：** 可以

## 4. 路线图（关口二）
**阿岚：** 排路线吧
**起元操盘：**
```

⑤ 规划保留成一页清单，挡在开发前（关口三）。
③ 凝露：截图转文字 → 课程/请假/续卡知识卡；验收：抽一成卡翻回原文都对得上（建议）

**阿岚：** 照你的建议
**起元操盘：** 1、2、3 记下了。花钱那件不在「照建议」里，单独问：客服平台 A 先不买，草稿您复制去发（推荐，和您的底线一致）B 现在买 C 交付时再说
**阿岚：** A。（阿岚，演练编的）
**起元操盘：** 决策两行已记（关口二；— 先不买平台）。第一站先派凝露蒸「请假」这块，开始吗？

## 演练中发现的问题
1. 流程卡第一节：小件走「①②⑥⑦⑧⑨」，没有 ⑤；可同一张卡又说「关口三照常挡在开发前」，关口三是 ⑤ 规划的产物。我把 ⑤ 留成一页清单，写进路线图。
2. caopan-getting-started 第 2 步：只写「跳过」用默认，没写主人说「先这样，直接干活吧」时剩下的题怎么办。我没填默认，写进「还没问的题」，过关口一后再问一句。
3. caopan-memory 第 1 节：「周一休息」既像项目的事，又像馆里的知识（组织层），表里没说做 Bot 用的业务事实放哪。我放进知识、记台账，不进档案。
4. caopan-relay、交接单卡第一节：没提资料里有会员姓名、手机号这类隐私怎么处理，memory 只管记忆。我在交接单「边界」写了打码。
5. caopan-brief 第 2 节第 4 问「资料新不新」允许跳过；可跳过用推荐项「今年的」，后来发现课程表是旧的。我标了待确认，复盘里建议这题不许跳过。
6. caopan-status 第 1 节：只拿到交接说明时，先说三行再问文件夹，可当时 check_caopan.py 跑不了，我只写了命令，没法照合格卡逐条对文件。

以上 6 条和「跳过就默认成今年的」那一处，2026-10-22 已按条改进流程卡、入门、记忆、交接单卡、需求整理、查进度（演练当场改）。
