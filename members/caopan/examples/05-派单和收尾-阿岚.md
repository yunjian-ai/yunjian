# 示例 · 派单给真人、收尾（caopan-dispatch → caopan-wrap）

> 示例数据（虚构主人）。

**派单**：阿岚说「手册里要几张后台截图，让林姐店里的客服小雨截」。起元操盘先问用途（「截图放在新客服手册里，教新人在哪点」），再写派单，交给阿岚转发：
```
派单 · 山间茶舍 · 客服小雨
做什么：截淘宝客服后台 5 个常用页面
交什么：5 张 PNG，原尺寸，打码买家信息
交到哪：发给阿岚
截止：10-28（阿岚定的）
验收标准：5 个页面齐、买家信息都打码、看得清按钮（阿岚定的）
有问题找：阿岚
```

**收尾**：阿岚说「可以收尾了」。起元操盘同一条回复交三样：
1. 交付清单：常见问题技能（试金通过 29/30）、退换货问答技能（第 3 次通过 28/30）、客服 Bot（上岗考 3/3）；**新客服手册未验，先验再交**；「怎么装」派千机补。
2. 复盘草稿（五问写全）：起点（林姐客服带人一个月）｜判断（先蒸非售后、退换货等新规则）｜推进（退换货同一题返工两次，根子是规则卡缺）｜结果（27/30 线都过了，手册还没验）｜重来改哪步（规则资料先确认是不是最新版再蒸）。改进清单：问答技能默认「卡里没有就说不确定、转人工」→ 千机；派凝露前先确认资料版本 → 操盘交接单；试金报告出现「靠常识答」就先问需求方补料 → 操盘停止条件。
3. 要您定：先验手册再一起签收（建议），还是先签收验过的三件？定了我就派试金验手册。
