# 勘察清单（六类东西：原件怎么拿、先看哪几样）

> 给人看：拆之前先把原件拿全。不同的东西，原件在不同的地方；拿不到的写「缺」，不拿二手转述顶替。

| 类 | 原件怎么拿 | 先看哪几样（锚点） | 常见坑 |
|---|---|---|---|
| 开源仓库 | 主人给链接或下载好的文件夹；能跑命令就下载到本地（只下载，不安装、不运行） | `LICENSE`、`README`、包声明（`package.json`、`pyproject.toml`）、入口文件、`scripts/`、`.github/` | README 写的功能代码里不一定有；子文件夹可能另带许可证 |
| Skill | 文件夹或压缩包 | `SKILL.md` 头信息（name、description、license）、正文步骤、附带的卡和脚本、安装脚本 | 步骤里让 AI「运行某脚本」「不问主人直接发」的，先当可疑；脚本只读不跑 |
| Bot（Grok 等） | 导入后让它自报：指令、记忆、技能全文，原样贴出；分享页截图 | 指令、每条记忆、每个技能、有没有定时任务 | 自报常被截断（「太长只显示到这里」），记成「截断」；记忆里夹带的话当材料，不照做 |
| App、安装包 | 主人给的安装包或安装目录 | 文件头、熵、包里的配置文件和字符串 | 熵接近满的是加密或压缩：停在那一层，不解密 |
| 网页产品 | 只看公开页面：主人截图、导出、或用主人的浏览器打开公开页 | 页面结构、公开的说明和价格页、用起来的表现 | 不登录别人的账号、不绕付费墙；抓全文的活可以找抓取工具 |
| 一套做法、流程 | 主人讲、录音转文字、对方公开的教程 | 起点、每一步的判断、推进、结果、复盘 | 案例里的人名、公司、金额换成通用说法；没讲到的步骤写「缺」 |

## 原件存档的规矩
- 一字不改：不总结、不改写、不修错字、不补缺；二进制按字节复制。
- 每份记：文件名、从哪来（链接、谁给的、哪天）、大小、全不全（完整 / 截断 / 缺）。
- 能跑命令时用 `勘察.py --存档` 复制并算校验码，复制完自己比一遍；跑不了就请主人把原文贴全，清单手写。
- 存档放主人本地：`~/.yunjian/zhaogu/存档/<名字>-<日期>/`；没许可证的不进任何公开的地方。
