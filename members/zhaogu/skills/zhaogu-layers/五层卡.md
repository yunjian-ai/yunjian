# 五层卡（L1～L5 每层问什么、交什么）

> 卡类：口径｜改了要回归考题

> 给人看：拆东西一层一层往下，每层站稳了再下一层：是什么 → 由什么组成 → 怎么运作 → 为什么这样 → 怎么复刻。跳层得出的是故事，不是结论。允许回头：上面一层的猜想，常要回下面一层补证据。

| 层 | 回答什么 | 怎么查 | 交什么 | 常见错 |
|---|---|---|---|---|
| L1 是什么 | 什么东西、什么形态、谁做的、授权状态 | 门禁结论＋勘察结果（体量、文件头、入口） | 一句话身份＋门禁结论 | 形态没定就猜内容 |
| L2 由什么组成 | 有哪几块、每块叫什么、谁包含谁、谁调用谁、数据怎么流 | 先找锚点（`SKILL.md` 头信息、`package.json`、指令和记忆、目录约定），再一层层往里 | 部件清单（名字＋一句干什么＋出处）＋关系 | 用「这类东西通常有……」补没看到的部件 |
| L3 怎么运作 | 输入什么 → 每一步做什么 → 输出什么 → 还动了什么（写文件、发网络、改设置） | 顺着步骤和代码走一遍；能安全试的（主人自己的环境、不外发）一次只改一个条件看变化 | 流程一行一步，每步带出处；副作用单列 | 把一次试出来的当规律；把宣传语当步骤 |
| L4 为什么这样 | 哪些是硬约束（平台限制、长度上限、兼容）、哪些是作者的取舍、代价是什么 | 注释、默认值、限制一节、版本记录、同一作者别的作品 | 两栏分开：「有据的」和「猜想（待验证）」 | 只说好处不说代价；把猜想写成意图 |
| L5 怎么复刻 | 别人不看原件也能照着做出来、还能证明一样 | 先跟主人定要「一模一样」还是「用起来一样」 | 复刻规格（格式见 zhaogu-absorb 的 `报告格式.md`） | 为了规格完整编细节；缺的写进「还不知道」 |

## 六类东西各层先看什么
- **仓库**：L2 看目录和包声明；L3 看入口和脚本；L4 看 README 的限制、提交记录。
- **Skill**：L2 看头信息、步骤、附带的卡和脚本；L3 顺着步骤走；L4 看「限制」「不做」一节。
- **Bot**：L2 看指令、记忆、技能、定时任务各有什么；L3 拿一句主人常说的话，顺着指令和技能推它会怎么回；L4 看规矩放在哪一层、为什么。
- **App、网页**：只看公开的界面、说明和用起来的表现；L3 写成「主人点了什么 → 它显示什么」。
- **做法、流程**：用五问——起点、判断、推进、结果、复盘；人名、公司、金额换成通用说法。

## 主人要到哪层
默认到 L4，再出吸收清单（zhaogu-absorb）；主人要真照着做一个，才做 L5。主人说「直接告诉我怎么复刻」：L1～L4 每层也要先写一两句（可以很短），再出 L5。
