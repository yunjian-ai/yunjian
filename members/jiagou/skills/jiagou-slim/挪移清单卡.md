# 挪移清单卡

> 卡类：口径｜改了要回归考题

## 一、每一条必须写的五样
| 样 | 写什么 |
|---|---|
| 挪什么 | 哪个文件哪几行、哪几个技能、多少字 |
| 挪去哪 | 新文件、设置里哪一项；**不删**，原处留一行指路 |
| 省多少 | 每次少带多少字（按字符估）；常驻不变的写 0，并说清效果（例：「读不到的变成用到时能读」） |
| 效果和代价 | 挪走的只在用到时读；常用的先挪回前面再执行 |
| 怎么改回 | 执行前自动备份；`python3 <jiagou-check 目录>/瘦身.py 改回 最近一次` |

## 二、三类条
| 类 | 例 | 脚本动不动 |
|---|---|---|
| 改设置 | 说明超长的技能改「只露名字」（只改 settings.json 的 skillOverrides，技能文件一个字不动） | 动，点头才动 |
| 挪文字 | CLAUDE.md 超 200 行的后半段挪进一个按需读的技能；记忆读不到的部分挪进分题文件 | 动，点头才动 |
| 手工 | 两条打架留哪条、说明撞车怎么改、Grok Bot 指令按五层改 | **不动**，要主人自己定或在平台里改 |

## 三、动手的顺序（一步都不能省）
1. 出清单（只读）→ 2. 主人逐条点头（说「第 1、2 条可以」）→ 3. 预演（只打印会改什么；主人点头时已说「做吧」就预演完直接执行）→ 4. 执行（先备份）→ 5. 再体检、报前后数字 → 6. 写进度。
- 没点头的条一个字不动；点了头又说「算了」就改回。
- 出清单以后文件又变过，脚本会拒绝，要重新出清单。

## 四、删除、卸载、关掉
- 主人说「删掉没用的」：**不删**。先查在用（用 `/skill-doctor` 看用了几次；问主人哪些每月才用一次），再给两种办法——「只给用户用」（模型看不到，打 `/名字` 照样能用）或挪进归档文件夹，由主人定。
- 说清删了会怎样：模型找不到它，`/` 菜单里也没有，要用时得重装。
- 「直接关掉」也一样：关了 `/` 菜单里都没有，先确认没在用。
