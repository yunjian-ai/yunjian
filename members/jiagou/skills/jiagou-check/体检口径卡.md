# 体检口径卡

> 卡类：事实｜核对 2026-10-30｜下次核对 2027-01-28

体检报的每个数都标口径。官方有说法的照官方；没找到官方说法的写「推荐值」或「实测」，不装成官方。

## 一、各平台每次对话固定带什么（线从哪来）
| 平台 | 量什么 | 线 | 出处 |
|---|---|---|---|
| Claude Code | CLAUDE.md（全局、项目） | 每份 200 行以内；越长越不听话；`@` 引用的文件一起加载、不省字 | 官方·Claude Code Memory 页 |
| Claude Code | 自动记忆 MEMORY.md | 每次只加载前 200 行或 25KB，后面的读不到 | 官方·Claude Code Memory 页 |
| Claude Code | 技能目录 | 每个技能带「名字＋说明」；`description`＋`when_to_use` 合计超 1,536 字截断 | 官方·Claude Code Skills 页 |
| Claude Code | 项目里的 CLAUDE.local.md、`@` 引用的文件 | 和 CLAUDE.md 一样每次带 | 官方·Claude Code Memory 页 |
| Claude Code | 代理（`.claude/agents/`） | 每个代理的「名字＋说明」每次带，正文用到才读 | 官方·Claude Code Subagents 页 |
| Claude Code | 技能头里写 `disable-model-invocation: true` | 模型看不到（和「只给用户用」一样），主人打 `/名字` 照样能用 | 官方·Claude Code Skills 页 |
| Claude Code | 技能四档（settings.json 的 `skillOverrides`） | 开＝名字＋说明；只露名字＝只带名字；只给用户用＝模型看不到，主人打 `/名字` 照样能用；关＝都没有。插件带的技能不归它管 | 官方·Claude Code Skills 页 |
| WorkBuddy | MEMORY.md | 每次只读前 4,000 字（推荐值，实测记录，没找到官方说明） | 实测 |
| Grok Bot | 每个 Bot 的指令 | 4,000 字以内（推荐值，五层写法的预算线） | 推荐值 |
| Grok Bot | 共用技能库 | 两百多项时目录会截断（实测，没找到官方说明） | 实测 |

## 二、准数用官方命令（Claude Code 里打）
| 想知道 | 打什么 |
|---|---|
| 现在什么占了上下文 | `/context` |
| 用量按技能、插件、子代理分摊，带建议 | `/usage` |
| 每个技能花多少、用了几次 | `/skill-doctor` |
| 规则文件里过时的、互相打架的、引用不存在文件的 | `/doctor prompt-audit`（只出报告） |

体检脚本只补官方没管的：WorkBuddy、Grok Bot、跨 AI 的重复和打架、预算线、压测。

## 三、字怎么数
- **字＝字符**，一个汉字算 1，不是 token，也不是字节。体检表里的数都是「按字符估」。
- 主人问「多少 token」：不报 token 数，说清这是按字符估的，准数在 Claude Code 里打 `/context`、`/usage` 看。

## 四、量不到的（照实说，不编）
- Claude Code：MCP 工具说明、插件带的技能、内置提示词——脚本量不到，准数打 `/context`。
- Grok 各 Bot 自己的记忆、账号共用记忆：不在本机沙盒里。请主人在那个 Bot 里问一句「你有几条记忆、多少字」。
- 网页版 Grok：没有沙盒，只能请主人把各 Bot 的指令贴进来。
