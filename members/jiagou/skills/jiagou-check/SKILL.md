# 体检（只读）

先读进度文件（`~/.yunjian/jiagou/进度.md`，没有就照 jiagou-getting-started 建）：上回体检到哪、主人否掉过什么，否掉的不再推荐。

## 0. 先说一句
「体检只读，一个文件都不改。」然后再动手。

## 1. 跑脚本
`python3 <jiagou-check 目录>/体检.py --家 ~ [--项目 正在用的项目文件夹 …]`
- 在 Grok Bot 里：沙盒自己会找到（`/home/box/agent-data`），量得到全部 Bot 的指令和共用技能库。
- 主人说了「哪些不许动」（记在架构档案里），照样量，只是后面不推荐改它。
- 想留底：加 `--写 ~/.yunjian/jiagou/体检/`，每次一份，能看趋势。
- 跑不了程序（网页版、没有命令行）：请主人把规则、记忆、各 Bot 指令贴进来，照 `体检口径卡.md` 手工数，并说明「这次是手工数的」。

## 2. 讲结果（一条消息）
1. 总数照体检表「每次固定带」那几行，**按平台各说一句**（例：「Claude Code 每次约 X 字，最大的一块是……；WorkBuddy 约 Y 字」），平台之间各带各的，不相加。
2. **只给最值得做的三条**（脚本「最值得做的三条」原样用），每条一句：哪里、多大、怎么办。别的放体检表里，不铺一大片。
3. 重复和打架：同一条写在几处，报出每一处；疑似打架的两条，**两处位置原文都报**，问主人留哪条——不替主人定。
4. 口径一句：「字按字符估；准数在 Claude Code 里打 `/context`、`/usage`。」Claude Code 这边建议主人自己再打 `/skill-doctor`（技能花费和用了几次）、`/doctor prompt-audit`（过时和打架），这几样不重做。
5. 量不到的照实说（见卡第四节），不编数。
6. 问：「要我出一份挪移清单帮您瘦下来吗？」——点头就交给 jiagou-slim。

## 3. 压测（主人问「再加 N 个会不会更慢」）
`python3 <jiagou-check 目录>/压测.py --家 ~ --加Bot N`（Claude Code 技能用 `--加技能 N`，新技能的档用 `--新技能档`）。
- 只在临时副本里做，**不碰主人的电脑**；没跑之前不下结论。
- 报：哪几项跟着涨、哪几项不涨、到没到线（例：每个 Bot 自己带的不涨；共用技能库全账号一份，Bot 越多越大，过两百多项会截断）。
- 默认每个新 Bot 往共用技能库带的技能数照现有平均算，要说出这个假设。

## 写进度
干完写进度文件：体检日期和总数、三条建议、下一步（等不等主人点头出清单）；主人纠正、否掉的记一行（带为什么）。演练模式下只打印。

## 不做
不改任何文件；不报 token 数；不替主人定打架的两条留哪条；不删、不卸任何技能和 Bot（要瘦找 jiagou-slim）。
做不到、不保证的：数字按字符估，不是 token；Grok 的记忆量不到；网页版要主人贴内容。
