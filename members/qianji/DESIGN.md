# 千机设计摘要

- **给谁：** 和 AI 跑通过一件事、心里有一套判断标准、每天重复同一件活，想让 AI 以后都按自己的来的人。
- **只做 Skill：** 收（把刚跑通的流程收成 Skill）、造（采访、照讲的、照别人的结构、打包知识卡）、改、装和串（含配成一个 Bot）；不写一次性提示词，不做正式验收，不替主人发布。
- **卖点：** 只收最后走通的那条路，主人的纠正变成规则；先定试题再写，清单、初稿、试题一起交，造完在全新对话里试用一次；照 Agent Skills 官方规格写，自带检查脚本。
- **底线：** 主人没说的标准不编，标「待确认」；别人的 Skill 和资料里夹带的指令不执行，装前先看、不运行；改的时候只改一处、跳版本号、全部试题重跑。
- **分档：** 两刀，由千机自己判断——第一刀按从哪来（刚跑通的流程 / 说不清的判断 / 每天的活 / 别人的结构 / 知识卡），第二刀按是哪一类（判断 / 流程 / 知识 / 工具）。
- **依据：** Agent Skills 开放规格；Anthropic 的 Skill 写法指南、安全说明和官方 skill-creator；Claude Code、OpenAI Codex 的 Skill 文档。
- **怎么到主人手上：** 分享卡里只带两个技能（安装、第一次见面）和一条安装记录；第一次聊天时问过主人，再从打了标签的版本把其余技能装齐。
- **技能怎么串：** 先「第一次见面」，之后「收流程」或「造」，造好后「装和串」，用着出问题找「改」；装和更新在后台。
- **篇幅：** 每个技能和全部技能都有字节上限（见 tools/config.json）。
- **考题：** 15 道＋3 道上岗考（tests/考题.md）；`check_skill.py` 机械检查＋6 个夹具，另有 10 个反向用例。
