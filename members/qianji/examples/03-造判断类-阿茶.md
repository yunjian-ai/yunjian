# 示例 · 造判断类

> 示例数据（虚构主人），用来看千机怎么回答。演示从「每天重复的活」起步造一个判断类 Skill：先请主人照平时讲一遍，没讲到的追问放进待确认，清单、初稿、试题一起交，依据检查写进去。

（还在演练。）

**阿茶：**

「再做一个：帮我判断进不进一款新茶。我每天都要看供货商发来的新茶，是这么看的：先算毛利，零售价减进价，得是零售价的一半以上；然后自己泡三泡，第三泡还有味才行；县城客人怕苦，太苦的不要。没有 SC 生产许可编号的，直接不看。」

**千机：**

先看该不该做成 Skill：你每天都看，会反复做；标准是你自己的；说得清；能拿你以前判过的茶对一对。收。

这是判断类（要一个结论：进还是不进）。你讲的是顺的时候，没讲到的我放进待确认，一起问。

```
我从这段里收到的做法（请确认）：
目标：判断一款新茶进不进，给结论＋理由＋依据哪条。
看什么：
1. 毛利：（零售价 − 进价）÷ 零售价 ≥ 50%
2. 耐泡：自己泡三泡，第三泡还有味
3. 口味：县城客人怕苦，太苦的不要
直接排除：没有 SC 生产许可编号
每次要你给的：【这款茶的名字、零售价、进价、SC 编号、三泡试喝记录】
交出来的样子：结论（进 / 不进 / 再看看）＋理由＋依据哪条
待确认：
1. 「太苦」怎么算？你试喝时怎么记？
2. 三条有一条不过，是直接不进，还是看别的能不能补？
3. 信息不全（比如还没试泡）怎么办？
4. 供货稳不稳要不要看？
```

**草稿：待确认 4 处、还没试用**

```
---
name: new-tea-pick
description: >-
  判断一盏茶舍进不进一款新茶，给结论、理由和依据哪条。阿茶说「这款新茶进不进」「帮我看看这个货」「供货商发来个新品你判一下」时用。
  只下判断，不写上架文案、不回客人、不砍价。
metadata:
  version: "1.0"
---
# 判断进不进新茶
## 目的
按阿茶的标准判一款新茶进不进。
## 要给什么
茶名、零售价、进价、SC 编号、三泡试喝记录。缺了见「意外怎么办」。
## 规则
看什么：
1. 毛利 =（零售价 − 进价）÷ 零售价，≥ 50% 算过
2. 第三泡还有味算过
3. 不太苦算过（怎么算苦：待确认 1）
直接排除：没有 SC 生产许可编号。
几条不过就不进：待确认 2。供货稳不稳：待确认 4。
依据检查：给结论前，每条理由都要对上上面一条；对不上的写「这条没有明确标准，是推测」。
## 意外怎么办
信息不全：待确认 3。
## 交什么
结论：不进
理由：毛利 40%，不到 50%（依据：看什么第 1 条）
## 不做什么
不写文案；不替阿茶跟供货商谈价。
```

**试题草案**

```

为什么选它：拿真实判过的案例重判
```

请给我 2～3 款你判过的茶，最好有一款当时犹豫过的。

**阿茶：**

「1 我试喝打 1 到 5 分苦，4 分以上算太苦。2 毛利和 SC 是死的，不过就不进；口味和耐泡差一条可以『再看看』，两条都差不进。3 没试泡就先说『试泡后再判』。4 要看，供货商得能连着供半年以上。例子：凤凰单丛，进 60 卖 150，第三泡还有味，苦 2 分，能供一年——进了。还有个高山绿茶，进 45 卖 80，我没进。」

**千机：**

四处定了，规则改成：

```
看什么：
1. 毛利 ≥ 50%（硬条件，不过就不进）
2. 第三泡还有味
3. 苦度 1～5 分，4 分以上算太苦
4. 供货商能连着供半年以上（硬条件，不过就不进）
直接排除：没有 SC 编号。
第 2、3 条差一条：再看看；两条都差：不进。
意外：没试泡，结论写「试泡后再判」，不猜。
```

试题定 3 道：凤凰单丛（平常的，该「进」）；高山绿茶（毛利 44%，该「不进」，依据第 1 条）；再加一道没试泡的（容易错的，该「试泡后再判」）。

试题里有进价，属于你档案里「店里内部数字」：只放在你自己存的试题里，不写进 SKILL.md。

自检照合格卡第四节逐条对过：头信息只有 name、description、metadata；正文 5 块和「不做什么」齐了；没有「酌情」。演练不建文件夹，没法跑检查程序。
