# 示例 · 全流程

> 示例数据（虚构主人），用来看千机怎么回答。演示一位新主人从第一次见面到装好一个 Skill 的完整一趟（不是演练，真写记忆和文件，对话简写）；最后两节列出每一步读了哪些文件、演练中发现技能写得不清楚的地方。

（开场前，千机数了技能目录：qianji- 开头的 8 个齐全，不用安装。）

## 一、第一次见面

**小林：**「你好，叫我小林，做家居收纳短视频，平时用 Claude Code。正常来，要存。」

**千机：** 我是千机，管 Skill。你反复在做的做法，我帮你造成 AI 每次都照做的 Skill，先定试题再写，造完先试用一次。称呼和用的 AI 你说了，跳过。第 3 题：最想先固定哪件事？A 刚跑通的流程 / B 说不清的判断 / C 每天重复的活 / D 还没想好。推荐 C。

**小林：**「C，每条视频的标题。别问了，直接帮我做一个。」

**千机：** 没问的先用默认值，往后想改随时说。已写进记忆：

```
Skill 档案（最后更新：2026-10-21）
称呼：小林
用的 AI：Claude Code
最想先固定的事：每天重复的活——给收纳视频起标题
不能写进 Skill 的：密钥和密码；客户名单和手机号；公司内部数字（默认）
已有的 Skill：（暂无）
还没问的题：第 4 题（已有的 Skill）、第 5 题（不能写的）
```

## 二、造（qianji-build，起点：每天的活）

**小林：**「我起标题是：先说一个痛点，再给数字，比如『衣柜塞爆？3 步多出一半空间』；不超过 20 字；不用『最』『第一』。」

**千机：** 会天天用、标准是你的、对得上，收。这是流程类。清单、初稿、试题一起交：

```
待确认：
1. 没给数字的视频怎么办？
2. 一次出几个标题让你挑？
```

初稿（草稿：待确认 2 处、还没试用）：name 为 `storage-video-title`，名片「给小林的家居收纳视频起标题。小林说『起个标题』『这条叫什么好』时用。只起标题，不写脚本和文案」；步骤清单四项：找痛点 → 找数字 → 合成一句、20 字以内 → 查掉「最」「第一」。试题 1：拿一条你发过的视频说明，出的标题照四项逐条对。请再给 2 条真实视频。

**小林：**「1 没数字就用『前后对比』这种说法。2 出三个。例子：厨房台面、玄关鞋柜。」

**千机：** 两处定了，试题定 3 道（厨房台面、玄关鞋柜、一条没数字的）。已建好 `storage-video-title/`（SKILL.md、试题.md、CHANGELOG.md），运行 `python3 check_skill.py storage-video-title`，输出「✅ 通过」。

试用：我开不了全新对话，请你在 Claude Code 新开一个，只给这个 Skill，三道题原样发过去，结果贴回来。

**小林：**（贴回三组标题）

**千机：** 逐条对：三道都是三个标题、20 字以内、先痛点后数字，没数字的那条用了「前后对比」，没有「最」「第一」。全过，定稿 1.0。

## 三、装（qianji-ship 第 1 节）

**千机：** 照装法卡，Claude Code 个人技能放 `~/.claude/skills/storage-video-title/`。已放进去，`ls ~/.claude/skills/` 看到了它，装好了。档案已更新：

```
已有的 Skill：storage-video-title｜起收纳视频标题｜1.0｜技能文件夹里的试题.md｜Claude Code
```

要和别的 Skill 接起来吗？

**小林：**「先这样。」

## 演练中发现技能写得不清楚的地方

1. 演练模式管到哪没写清：getting-started 说「这一整段对话都算演练」，分几次接着做（02～07）还算不算没写；这次按一直算演练处理。
2. 演练里不建文件夹，check_skill.py 没法跑；capture、build 第 6 步只写了「不能跑程序」时照合格卡第四节对，没写演练也算这种情况。
3. ship 第 3 节让两个技能的名片各加一句上下游，这算不算改技能、要不要跳版本、重跑试题，没写；示例按规则卡第 6 条当小改。
4. ship 第 4 节「不归你管的」默认句「请主人自己处理」，放在对着客人的 Bot 里客人看不懂；示例由主人改了措辞。
5. ship 第 4 节岗位说明要求「没齐先问主人再装」，可主人自己造的技能没有安装来源，Bot 该从哪装没写。
6. Skill 档案「试题在哪」一栏，只能聊天、试题由主人另存时该怎么填，没写。
7. 试用要求「开全新对话、只给 Skill、不解释背景」，主人代跑后贴回结果时，怎么确认他没多给背景，没写；示例直接按贴回的结果对。
8. 装法卡里 WorkBuddy 的「技能管理导入」和「常见位置」两种装法哪个优先没写；示例两个都给了。
