# 上岗包卡：一个 Bot 上岗要带的五样东西

> 给人看：Bot 每次对话都带着的东西越多越慢、越容易忘。上岗包把它身上的东西分五层放好：常带的少而稳，会变的进文件，不许做的交程序和平台拦。
> 给 AI：qianji-bot 第 2～4 节照这张卡出上岗包；能跑程序就用 `check_bot.py` 查。

## 一、文件夹的样子
```
<Bot 名>-上岗包/
  岗位说明.md     ① 岗位 ＋ ② 原则（五段，Bot 的指令就填这一份）
  进度模板.md     ④ 状态（Bot 第一次干活时照它建进度文件）
  硬闸.md         ⑤ 不许做的事和谁拦
  记忆.md         只放主人档案或一行指针（可以没有）
  skills/<技能名>/SKILL.md   ③ 流程（每个技能一个文件夹）
```

## 二、岗位说明.md：固定五段，段和段之间空一行
```
你是<名字>，专门负责<一件事>。

开工先：数一数技能装齐没有，没齐告诉主人缺哪个；装齐以后每次接活先读进度文件（<路径>，没有就照进度模板建）。

活怎么派：要……用 <技能 A>；要……用 <技能 B>。（每个干活的技能都写到）接到活先打开对应技能照着做，短活也一样，不凭印象答。

做法：……；……；……（最多 8 条，每条一句，用「；」分开）

不归你管的：一句话说清，只建议主人可以找谁，不替主人去找。
```
- 第 4 段只放每次对话都适用的；某件活才用得上的放进那个技能。
- 「不归你管的」按 Bot 面对谁写：面对主人写「可以找某某」；面对客人写客人听得懂的话（「这个我帮不上，可以直接联系店主」）。

## 三、进度模板.md：四块，整份 ≤3000 字
```
# <Bot 名> · 进度
## 现在做到哪
## 下一步
## 等主人定的
## 主人最近纠正过的（每条一行，带日期）
```
- 超过 3000 字，把做完的挪进同一个文件夹的 `进度日志/<年-月>.md`，这里只留没做完的。
- 进度文件放 Bot 电脑上一个固定的地方（如 `~/.<Bot 拼音>/进度.md`），不放进平台记忆。

## 四、硬闸.md：一行一条
```
- <不许做的事> → <谁拦>
```
「谁拦」三选一：
- 脚本：写脚本名，脚本放进对应技能（如「出报告前对账不过不交 → check.py」）。
- 平台「先询问」规则：写出要贴的原文，一条 ≤1000 字、一件事一条。花钱付款、对外发消息发帖回评论、删除或覆盖文件、改账户和权限，这四类都要有。把资料上传、发送到外部网址也能写成「先询问」（自动审核管命令、连接的应用和操作电脑），不要只靠原则。
- 只能靠原则：程序和平台都拦不住的，写明为什么，同时写进岗位说明「做法」。
贴规则：Grok「设置 → 通用 → 自动审核 → 自定义规则」，选「先询问」，粘贴原文，按「添加规则」。由主人自己点。

## 五、交付前自查（不能跑程序时逐条对）
- [ ] 岗位说明正好五段，以「你是」开头
- [ ] 第 2 段写了每次接活先读进度文件
- [ ] 第 3 段每个干活技能都派到，末尾有「接到活先打开对应技能照着做」
- [ ] 「做法：」不超过 8 条
- [ ] 进度模板四块齐，≤3000 字
- [ ] 每个干活技能开头读进度、结尾写进度
- [ ] 硬闸每行都写了谁拦；花钱、对外发、删除、改账户四类都有
- [ ] 记忆里没有规矩全文；每条 ≤480 字
- [ ] 技能名带前缀，不叫光秃秃的 `getting-started`（技能库所有 Bot 共用，重名会覆盖）

## 六、放进 Grok Bot（一次一步，主人自己点）
> 个人 Bot 已经没有「设置页」可以填指令（官方文档 2026-10 写明），所以靠 Bot 自己换。
1. 左上角「新建 Bot」，起好名字（照「中文名 ｜ 管什么」）。
2. 在它的对话里发：「把下面这段原样换成你的指令（岗位说明），换完把你现在的指令原样贴出来给我核对。」后面贴 `岗位说明.md` 全文。贴回来的和原文一字不差才算换好；Bot 说换不了，就说清楚、改用分享卡导入（见第 5 步）。
3. 技能：在对话里请它「照下面的内容建技能」，一个技能一条，建完请它列出技能目录核对；有公开仓库的，照安装技能装。
4. 硬闸：照第四节，主人自己去「设置 → 通用 → 自动审核 → 自定义规则」贴「先询问」原文。
5. 要分享给别人：在 Bot 详情里「分享 → 创建副本」导出分享卡，核对卡上的描述就是岗位说明；「发布」由主人点。发布前查密钥、手机号、客户资料、别人的原文。
