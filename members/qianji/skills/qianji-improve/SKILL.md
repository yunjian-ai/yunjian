# 改一个 Skill

## 0. 开工前
- 读记忆里的「Skill 档案」，找到这个 Skill 的版本和试题在哪。
- 读 qianji-build 里的 `规则卡.md`，全程照做。
- 要拿到三样：现在的 SKILL.md 全文、它的试题（没有就先补，照 `试题卡.md`）、这次出问题的真实例子（主人说了什么、它答了什么、主人觉得该是什么）。缺哪样问哪样，一次问一样。「叫不出来」只拿到名片原文时，先给名片草稿，再要全文核对。缺试题时不停下：先改规则交草稿，同时请主人给真实例子。

## 1. 认毛病，选改法
| 毛病 | 怎么改 | 版本 |
|---|---|---|
| **判错了 / 做错了** | 找到是哪条规则没写、写得含糊、还是两条打架；**只追加或改那一条**，写成通用规则，不写死这次的例子（例：客户问的是「孕妇能不能用」，规则写「涉及特殊人群的，先说清适用范围」，不写「孕妇能用」）；其他规则不动 | 小数位加一 |
| **标准整个变了** | 不在旧规则上打补丁：把新标准重新收一遍（采访或请主人讲一遍，照 qianji-build 第 1 节），试题跟着重定；旧版先整个复制一份，放在技能目录**以外**的文件夹（如「Skill 备份/<name>-1.x」），放在技能目录里会被当成另一个技能；名字不改 | 整数位加一，小数归零 |
| **叫不出来** | 名片太空：照 `合格卡.md` 第二节第 1 条重写——第三人称、写做什么和什么时候用、带主人会说的词，最要紧的放前面；照 `试题卡.md` 第二节写 10 句名片试题 | 小数位加一 |
| **乱出来** | 名片收窄，写上「不做什么」；把这次误叫的那句话放进「不该叫」的名片试题 | 小数位加一 |
| **太长、太乱** | 长规则、例子挪到附件；同一个意思写了两遍的合并；整理只在跳整数版本时做 | 跟着大版本走 |
| **格式不合规格** | 照 `合格卡.md` 第一节改（常见：头信息里单独一行 version，要挪进 metadata） | 小数位加一 |

拿不准是「判错」还是「标准变了」：问主人一句「是这次个别没判对，还是你整个想法变了？」
顺手发现格式不合规格（如单独一行 version），一起改，算同一次小改，版本只加一次。看到别的缺口（缺依据检查、分数没写细），列在改动单「看到但没动」里建议，主人没让改就不动。

## 2. 写出改动
- 新加的规则在交给主人的版本里标【新增】，改过的标【改】，主人确认后去掉标记。
- 版本号改在头信息 `metadata` 的 `version` 里。
- 改动记录（CHANGELOG.md）加一行：`日期｜旧版本 → 新版本｜改了什么｜为什么（哪个例子引起的）`。

## 3. 重跑
- 把这次出问题的例子加进试题。
- **全部试题重跑一遍**（开全新对话，只给新版 Skill），逐条对：这次的对了，以前对的也还对，才算改完。以前对的变错了，退回去换个写法。规则本身缺数、判不出过没过的，算「部分通过」，在改动单里写明并建议补。
- 能跑程序就再运行一次 `check_skill.py`（在 qianji-build 里）。
- 开不了新对话：把试题和试法交给主人。

## 4. 交付
照规则卡第 9 条交，附一张改动单：
```
改了哪个 Skill：<name>  版本：1.0 → 1.1
改动：【新增】… 【改】…
为什么：…
重跑试题：N 道，全过 / 第 X 道没过（原因、怎么处理的）
```
更新 Skill 档案里这个 Skill 的版本（演练模式只打印）。

## 不做
不推翻重写已经对的规则；不为一个例子写死规则；不跳过重跑；不改主人没让改的 Skill。
