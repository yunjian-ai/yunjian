# 试题卡：先定怎么算对，再写 Skill

> 给人看：写 Skill 之前，先定几道试题和「这样才算对」。Skill 写完拿它们试；以后每改一次，把它们全部重跑一遍，防止改好这里、坏了那里。
> 给 AI：试题和 Skill 放在一起交给主人（建议存成 Skill 文件夹里的「试题.md」，正文不引用它，平时不占地方）。

## 一、内容试题（2～3 道，必须来自真实例子）
每道写三样：
```
试题 1
给它什么：【主人平时会怎么说＋要用的材料】
这样才算对：【判断类写主人自己的结论和理由；流程类写成品必须有的几样；知识类写正确答案和依据哪张卡】
为什么选它：【它考的是哪条规则，或哪个容易错的地方】
```
- 至少有一道「平常的」、一道「容易错的」（主人以前纠正过的、规则边界上的）。
- 知识类另加一道「资料里没有」的，正确答案是「没有」。
- 工具类另加一道「输入是错的」的，正确结果是好好报错。
- 没有真实例子，就请主人给一个；实在没有，标「待确认」，先别定稿。知识类可以先照卡拟几道，再请主人换成平时真会被问到的。

## 二、名片试题（测会不会被叫出来）
写 10 句主人可能说的话：
- **5 句该叫它的**：说法要不一样，有正式的、随口的；有一句不点名「技能」但明显需要它。
- **5 句看着像、但不该叫它的**：和它沾边，其实该用别的（例：泡茶技能，不该叫的是「龙井多少钱一斤」「帮我写一段龙井的文案」）。太明显无关的不算数。

## 三、怎么试
1. 开一个**全新对话**，只装这个 Skill，不解释背景。
2. 把每道「给它什么」原样发过去。
3. 拿结果和「这样才算对」逐条对；有一条不对就算没过。
4. 没过：先找是哪条标准没写清、还是漏了，回去问主人补，不靠多加几句「一定要」硬压。
5. 只能聊天、开不了新对话的环境：把试题和试法写给主人，请主人在新对话里跑，结果贴回来再对。
