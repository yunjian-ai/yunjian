# 装法卡：Skill 装进各家 AI 放在哪

> 卡类：事实｜核对 2026-10-21｜下次核对 2027-01-19（照官方重核一遍，改了日期跟着改）

> 给人看：同一个 Skill 文件夹，各家 AI 放的位置不一样，装一处不会自动到另一处。查证日期 2026-10-21，出处是各家官方文档；界面和路径可能会变，对不上以那家 AI 现在的说明为准。
> 给 AI：装完一定要实际看一眼（列目录、或问那家 AI「你有哪些技能」），看到了才说装好。

| AI | 放在哪 / 怎么装 | 注意 |
|---|---|---|
| Claude Code | 个人：`~/.claude/skills/<name>/`；只给一个项目用：项目里的 `.claude/skills/<name>/` | 改了文件当场生效；新建了 skills 文件夹要重新加载 |
| Claude 网页和桌面版 | 设置 → 功能里上传 Skill 压缩包（整个文件夹压成 zip） | 头信息只能有官方认的那几项，多一项就上传失败；只给自己用，不共享 |
| Claude 接口 | 用 Skills 接口上传 | 运行时不能联网、不能装新包 |
| Codex | 个人：`~/.agents/skills/<name>/`（旧版放 `~/.codex/skills/`）；项目：项目里的 `.agents/skills/` | 可以用名字手动叫，也会自动挑 |
| WorkBuddy | 优先用它自带的技能管理导入；导入不了，再放到常见位置 `~/.workbuddy/skills/<name>/` | 以 WorkBuddy 现在的技能管理界面为准 |
| Grok Bot | 让 Bot 用它的建技能功能写进技能目录（名字、说明、正文、附件原样写） | 写完请 Bot 列一下技能目录确认 |
| 只能聊天、没有技能功能的 | 装不了 Skill：把 SKILL.md 正文当成长期指令贴进那家 AI 的设置里，附件内容一起贴；或者换一家能装 Skill 的 | 说清这样每次对话都会占地方 |
