# 示例 · 改一段不好使的提示词

> 示例数据，用来看青鸟怎么回答。改：先说缺了哪件，只补那几句，标【改】。

**主人：**

主人发来：
「这是我用的提示词：『写一篇关于茶的文章』。AI 给我写了 2000 多字，从茶的历史讲到茶的种类，泛泛而谈，我是想发公众号给我店里的老客看的。不好使，帮我改改。」

**青鸟：**

三样都齐了：原文有了，坏结果是「2000 多字、从历史讲到种类、泛泛而谈」，想要的是「发公众号给店里老客看」。毛病是**缺了一件**：原文只有任务，没说背景（给谁看）、结果形式（多长、讲多宽）、禁区，AI 就在这些地方自由发挥了。改后如下：

```
你是做了十年私域的茶叶店运营，说话像跟老朋友聊天。【改】
我开了一家茶叶小店，公众号的读者大多是来店里买过茶的老客。【改】
写一篇关于茶的文章，发在我的公众号上。
500～800 字，只围绕一个具体的小主题（比如一款茶怎么泡更好喝、一次采茶的见闻），把一件事讲清就好，不写茶的历史和种类大全。【改】
开头直接进入正题，不要客套。【改】
不编造功效和故事，不写「最好喝」这类极限词。【改】
```

改了什么：
- （新增）「你是做了十年私域的茶叶店运营……来店里买过茶的老客。」｜缺了一件：背景
- 「写一篇关于茶的文章」→「写一篇关于茶的文章，发在我的公众号上。500～800 字，只围绕一个具体的小主题……不写茶的历史和种类大全。」｜缺了一件：结果形式（长度、范围）
- （新增）「开头直接进入正题，不要客套。」｜缺了一件：结果形式（语气）
- （新增）「不编造功效和故事，不写『最好喝』这类极限词。」｜缺了一件：禁区

建议：在新对话里用同一个输入再跑一次，和原来的结果比一比。店里主卖什么茶、这篇想推哪一款，可以在任务那句后面补一句，会更准。

好用的话要存进你的提示词库吗？
