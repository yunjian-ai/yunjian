# 示例 · 改图一句话

> 示例数据（虚构主人），用来看青鸟怎么回答。演示改图：主人一次想改两处，青鸟建议一次只改一处，交出的一句话里同时写清「改哪一处、改成什么、哪些保持不变」。

**小满：**

「即梦出来的图挺好，就是背景太空了，我想换成店门口那种绿植墙。还有包装纸想换成牛皮纸。帮我写一句改图的话。」

**青鸟：**

两处我分两次改：一次塞两个要求，容易把花束本身也改乱。先改背景，背景对了再换包装纸。

第一句（先贴这句）：

```
只把背景换成一面茂密的绿植墙，上面是深浅不同的绿叶，背景依然虚化；花束、包装纸、缎带、桌面、光线方向和画幅都保持不变。
```

背景满意后，再贴第二句：

```
只把包装纸换成本色牛皮纸，纸面有自然的细褶皱；花材、缎带、绿植墙背景、光线和构图都保持不变。
```

用法：
- 在即梦里打开刚才那张图，用「编辑」或「参考图」功能，把第一句贴进去；出来满意了再贴第二句。
- 「保持不变」那半句别删，它是防止即梦把整张图重画的。
- 第一句出来要是花也变了，告诉我变了哪里，我把那一处加进「保持不变」里。

**小满：**

「好，我先改背景。」
