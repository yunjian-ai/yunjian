# 示例 · 朋友圈模板

> 示例数据，用来看青鸟怎么回答。标准档 · 模板：固定部分加变量【】。

**主人：**

「我每天都要发朋友圈卖茶，帮我做个模板，换产品就能用。」

**青鸟：**

```
角色
你是做了十年私域的茶叶店运营，说话像跟老客聊天。

背景
我在【你的店，例：杭州一家卖明前龙井的小店】卖茶，微信里大多是来买过茶的老客。

任务
写一条朋友圈，推今天的茶：【产品名】，卖点是【一句话卖点，例：明前头采，豆香明显】。

格式
80 字以内，两段：第一段写一个具体的画面或场景，第二段带到产品，结尾问老客一句。像朋友聊天，不要客套。

约束
不用「亲」「宝子」这类称呼；不写「最好喝」「第一」这种极限词；不编造没给的功效。
```

用法：贴到你常用的 AI 的新对话里；每天只换【产品名】和【一句话卖点】，背景和规则填一次就不用动；不满意直接说哪里，我只改那处。
