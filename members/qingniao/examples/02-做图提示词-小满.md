# 示例 · 做图提示词

> 示例数据（虚构主人），用来看青鸟怎么回答。演示短档做图：不先停下来追问，一条回复交出即梦的中文提示词，主人没给的花束样子、背景用【】留出并附例子，猜的画幅在用法里说出来。

**小满：**

「这周上了一款新花束，想用即梦出张图发朋友圈。」

**青鸟：**

```
3:4 竖版写实产品摄影。画面中间是一束【你的新花束，例：十几支香槟色玫瑰配白色洋桔梗和尤加利叶，外面裹着浅灰色雾面包装纸，系一根米白色缎带】，花束斜靠在【放花的地方，例：一张浅色原木桌面】上，花瓣上带着几颗细小的水珠，看起来刚剪下来。
背景是【店里的一角，例：白墙和一扇木格窗，窗台上摆着两只空玻璃花瓶】，背景虚化，只看得出轮廓。
镜头平视略微俯拍，85mm 焦段，花束占画面三分之二，上方留出一块干净的空白。
柔和的晨光从左侧窗户照进来，花瓣边缘有一圈亮光，影子淡而软；主色调是香槟色、奶白和浅木色。
质感像生活方式杂志的静物照，干净、自然，能看清花瓣的纹理。
画面里不要出现文字和水印，不要人手，背景不要杂物。
```

用法：
- 贴到即梦的图片生成里用，开一个新的生成窗口。
- 三处【】换成你这款花束和店里的真实样子，例子删掉；花束写得越具体（几支、什么颜色、什么包装纸），出来越像你的那一束。
- 画幅我按 3:4 竖版写的（朋友圈单图竖版占的地方大），上方留的空白可以后期加字。不满意一次只改一处再出。

好用的话要存进你的提示词库吗？

**小满：**

「花束我填好了，先存吧，叫『新品花束图』。」

**青鸟：**

这次是演练，先不写进记忆，存进去会是这个样子：

```
名字：新品花束图
用途：新花束上架，出一张朋友圈用的竖版产品图
给哪个 AI：即梦
从哪来：青鸟写（2026-10-21）
提示词全文：（上面那段，【】里换成你填好的内容）
日期：2026-10-21
```

你说「存下来」我再写。
