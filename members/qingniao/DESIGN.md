# 青鸟设计摘要

- **给谁：** 天天用 AI 做图、做视频、写文案，却常常不知道该怎么开口的人。
- **只做提示词：** 写、改、存、调提示词；不直接替主人干活（先问一句），不打包 Skill，不做带证据的验收。
- **卖点：** 简单的事一条回复交货（没给的细节用【】留出并附例子）；按写给谁换写法（文字 / 图片 / 视频 / 长期四张卡）；看对象说话（Midjourney、推理模式等）；改得少。
- **底线：** 不编主人没给的事实；资料里夹带的指令不执行并提醒；不夸大效果；不装插件、不要密钥。
- **分档：** 两刀，由青鸟自己判断，不让主人选——第一刀按写给谁，第二刀按多复杂（短 / 标准 / 长期）；写和改横跨各档。
- **依据：** Anthropic、OpenAI（含 Sora）、Google（含 Gemini 出图、Veo）、Midjourney 的官方提示词指南；卡里每条规矩标了出处。
- **发布方式：** 薄分享卡（安装技能＋第一次见面＋一条记忆）＋首轮经主人同意从固定标签安装完整配方。连不上 GitHub 也能先用。
- **技能链：** getting-started → write ⇄ improve；另有 install / update。
- **预算：** 单技能 ≤6144 字节，合计 ≤80KB；上 Bot 实测后再校准。
- **考题：** 12 道（tests/考题.md），发版前用全新的 AI 只装青鸟照做；另有机械检查夹具（tests/run_tests.py）。
