# 改提示词

先读进度文件（`~/.yunjian/qingniao/进度.md`，没有就照岗位说明里的四块建）：上回做到哪，有断点就接着做，不从头再问。

目标：让主人手上这段提示词变好用，改得越少越好。保留主人原来的话和结构。

## 1. 先弄清楚
- 要三样：**提示词原文**、**它出的坏结果**、**主人想要的样子**。缺坏结果或想要的样子，问一句（带选项：太长 / 太泛 / 跑题 / 风格不对 / 漏了东西）。
- 认出是写给谁的（文字 / 图片 / 视频 / 长期），读 qingniao-write 目录里对应的卡和 `规则卡.md`。

## 2. 判断是哪类毛病
| 毛病 | 看出来的样子 | 怎么改 |
|---|---|---|
| 说得模糊 | AI 理解成别的意思 | 把那句换成具体的话，或加一个例子 |
| 漏了情况 | 某类输入它不会处理 | 追加一条规则覆盖这种情况，不重写整份 |
| 前后打架 | 两条要求互相冲突 | 说清谁优先，或合并成一条 |
| 只对一个例子有效 | 换个输入就不行 | 把绑在某个例子上的话改成通用的说法 |
| 结果不稳 | 同样的输入每次不一样 | 给那条判断加明确的条件，缩小自由发挥的空间 |
| 缺了一件 | 泛泛而谈、长度乱、语气乱 | 补上缺的那件：背景 / 结果形式 / 禁区（见 `规则卡.md` 第 2 条） |

图片视频再看：骨架里缺了哪块（光线、机位、动作节拍……）；给 Midjourney 的是不是太长、写了「no xx」。

## 3. 改
- 只改能堵住这次毛病的最少几句；不顺手改别的句子，不换掉主人的说法。
- 图片视频：**一次只改一处**，让主人出一张或一段看看，再改下一处。 [官方·OpenAI]
- 长期规则：照「追加，不重写」；版本号加一（小改小数位，推翻原有判断整数位）。

## 4. 交付
```
（改后的完整提示词，可以直接复制使用；代码块里不加任何标记，免得主人把标记一起贴进 AI）
```
- 改了什么：列在代码块下面，每处一行，「原句 → 新句｜哪类毛病」；原来没有、新加的写「（新加）→ 新句」。
- 建议：在新对话里用同一个输入再跑一次，和原来的结果比一比。
- 最后问一句：「好用的话要存进你的提示词库吗？」主人说存，照 qingniao-write 第 5 节存。

## 写进度
干完写进度文件：做到哪、下一步、等主人定什么；主人纠正过的记一行（演练模式下只打印）。

## 不做
- 不把主人的提示词重写成另一个东西；主人要推倒重来，转 qingniao-write。
- 改不改由主人定：主人只说「看看哪里不好」，就只列毛病，不动手改。
