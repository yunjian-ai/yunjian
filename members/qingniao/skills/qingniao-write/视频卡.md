# 视频卡

> 先过 `规则卡.md`，这里只写视频的骨架、分段、写全和修改。

## 骨架 [官方·OpenAI Sora 指南；官方·Google Veo 指南]
1. **场景和人物**：在哪、什么天气时间；人物长相、服装、道具写具体
2. **镜头**：景别（远景 / 中景 / 特写）、角度（俯 / 平 / 仰）、运动（固定、缓慢推近、跟拍、环绕）、焦段和景深
3. **动作写成节拍**：「她走四步到窗边，停一下，拉开窗帘」，不写「她走过房间」 [官方·OpenAI]
4. **光和色**：光源和质感＋2～3 个色彩锚点（「暖色台灯，窗外冷蓝；琥珀、米白、胡桃木」）[官方·OpenAI]
5. **声音**：环境声、音效、对白各写一句；对白要短，能在时长内说完；不要音乐就写明 [官方·Google；官方·OpenAI]
6. **风格和画质**：一段话说清整体质感（写实 / 动画、胶片感、色调）
7. **避免**：不想出现的

## 写全：模型不会替你补
- 情绪拆成看得见的动作：写「嘴角往上一提，眼睛眯起」，不写「开心」。
- 环境里动的东西写出来：风吹衣角、热气上升、灰尘在光里飘。
- 光怎么照在人和物上写出来。

主人没说用什么视频工具：写通用的中文版，用法里说一句「在别的工具上可能要调」。

## 多长写多细 [官方·OpenAI]
- 要画面准、要一致：写细。
- 要创意、想看意外效果：写简，只写场景、人物、氛围。
短档默认写细；长于 10 秒左右照下面「分段」写；主人说「随便发挥」才写简。

## 分段（超过一个镜头，或长于 10 秒左右）
- 按时间分段，每段写起止时间（「0–5 秒」「5–10 秒」），每段一个主要动作。
- **每段都重复**人物外观、光线、人物站位——模型跨段不记事，不写「同上」。
- 全片统一的画质、风格单独写一段，标明「每段都带」；需要时在最后加一段风格总控。
- 系列（多个片段拼一个故事）走长期档：先问清故事、段数、每段时长，再写。

## 改 [官方·OpenAI]
- 一次只改一处，明确说改什么（「同样的镜头，换成 85mm」）。
- 接近满意时，拿那版当参考，只写要调的地方。
- 反复失败就先简化：固定机位、简化动作、背景清空，出来了再一点点加。

## 交付样子
```
（提示词；分段的按时间写）
```
用法：贴到【工具】；时长我按【15 秒】分的段；不满意一次只改一处再出。
