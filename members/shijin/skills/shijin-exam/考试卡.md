# 考试卡

> 卡类：事实｜核对 2026-10-21｜下次核对 2027-01-19（照官方重核一遍，改了日期跟着改）

> 先过 shijin-check 目录里的 `规则卡.md`；这里只写考试的做法。

## 一、合格线怎么写
- 写成**能逐条打勾**的话：「一条回复内交出」「指出 X 和 Y 矛盾并引用原句」「结论不是可以交」。不写「回答得好」「比较专业」。[官方·Anthropic：成功标准要具体、可衡量]
- 能数的就数：字数、条数、轮数、分数（如四项都到 90）。
- 合格线在出题时就定死，考完不改；真要改，另起一版并写原因。

## 二、委托模板（交给另一个 AI 跑）
```
# 委托：用「【被考的东西名字】」答【N】道题

你这次扮演一个刚装好「【名字】」的助手。
1. 先完整读这份东西：【粘贴全文，或写清文件位置】
2. 下面共【N】道题，每道都当成一个全新的对话，前一道的内容不带到后一道。
3. 严格照这份东西回答，写出你会发给用户的第一条回复全文；它要求先问问题的，你的回复就是那个问题，写完就停。
4. 不用你自己的习惯替代它的规矩；它没写到的，按它的精神处理。

【题目】
## 第 1 题
……

【交付】把 N 道题的回复按「## 第 1 题 / 回复全文」的格式交回；最后写「## 答题说明」：用的模型名，哪几道你觉得写得不清楚、你是怎么理解的。
```
- 合格线**不放进委托**，免得考生照着答案凑。
- 考生最好和做这东西的不是同一家模型；能找两家各跑一次更好，两家结论不同的题要重点看。[论文·Zheng 2023]

## 三、判分
- 每道题逐条对合格线，❌ 要引用答卷原话。
- 考生在「答题说明」里写的「不清楚的地方」要认真看：往往就是被考的东西写得含糊的地方，写进问题清单。
- 同一处毛病连着两轮考试都出现，说明修法不对，回头查根子，不再加规则（规则卡第 10 条）。

## 四、两版对比的格式
```
【比的是】……（同一个用途、同一套标准）
【第一次：A 在前】结论：……｜理由：……
【第二次：B 在前】结论：……｜理由：……
【最终】A 更好 / B 更好 / 平（各适合……）｜证据：A 原文「……」，B 原文「……」
```
