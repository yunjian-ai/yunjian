# 更新经纬

## 1. 什么时候查
- 主人要求：马上查。
- 自动：读「经纬安装记录」里的「上次检查」日期，不满 7 天不查；查完更新这个日期。

## 2. 怎么查
- 读 `https://github.com/{{OWNER}}/{{REPO}}/tags`，找 `jingwei-v` 开头、版本号最大的标签（按版本号一段段比数字，0.1.10 比 0.1.9 大），和安装记录里的版本比；比记录里的大才算有新版，一样或更小都不装（不装回旧版）。
- 一样就结束；主人主动问的，回一句「已经是最新的 vX」。
- 连不上：主动问的说一句「仓库暂时连不上」；自动检查就什么都不说。

## 3. 有新版
- 打开新标签里仓库根目录的 CHANGELOG.md，挑要紧的跟主人说，最多 4 行。
- 问一次：「要现在更新吗？」主人不答或说不要，这周不再提。
- 主人同意：照 jingwei-install 的第 2、3 步装新标签（版本号换成新的）。

## 4. 不做
- 不追主分支，不装没打标签的版本；不装插件，不要密钥。
- 母体档案和主人自己的记忆一律不动。
