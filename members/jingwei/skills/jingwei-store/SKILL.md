# 存成底座

先读进度文件（`~/.yunjian/jingwei/进度.md`，没有就照这四块建：现在做到哪、下一步、等主人定的、主人最近纠正过的）：上回做到哪，有断点就接着做，不从头再问。

## 0. 开工前
- 读 `载体卡.md`、jingwei-frame 的 `母体格式.md`，和记忆里「母体档案」的「母体放哪」「AI 能做什么」。

## 1. 选放哪
照 `载体卡.md` 第一节，按主人的环境选，一句话说清为什么：
- 能写文件：建 `<名字>-母体/` 文件夹，照 `母体格式.md` 七样写；用 Obsidian 就把文件夹放进库里。
- 只用飞书：照 `载体卡.md` 建多维表格（每类东西一张表，关系用双向关联，要带出处、时间的关系单建关系表），根、规则、地图放一篇文档。能用飞书命令行就直接建，不能就把表头和行列给主人照着建。
- 只能聊天：按母体格式分段发，每段标好是哪个文件，请主人存下。
选好放哪以后**顺带一句**：现在用不着数据库、数据仓库、图数据库（这么大的母体，文件夹或一张多维表格就够），什么时候才要（一句，照 `载体卡.md` 第二节），免得主人以为还得另买另装。主人专门问「要不要上」：照 `载体卡.md` 第二节照实判断，讲清什么时候才值得、母体怎么接过去；不默认替主人搭。

## 2. 写地图和给 AI 的用法
- `05-地图.md`：一句根，按维度列东西；「给 AI 的用法」照 `载体卡.md` 第三节写（先读根和规则 → 按名字和别名找东西 → 顺着关系走 → 要依据看证据；母体里没有的答「还没有」，不编）。
- 关系总表由脚本汇总，不手抄。

## 3. 跑检查
能跑命令就跑：
```bash
python3 <本技能目录>/check_mother.py <母体文件夹>
```
- 每条 ❌ 照提示改，改到一条不剩；⚠️ 是提醒（孤立的东西、待确认还有几处、空枝空着），念给主人听，主人定要不要改。
- 清零后加 `--map` 把关系总表写进地图。
- 跑不了命令：照 `母体格式.md` 和 `母体卡.md` 第三节的九条合格线人工对一遍，说一句「这次是人工对的」。

## 4. 用真动作验
- 让主人的 AI（或你自己，新开一段）只读 `05-地图.md` 和母体文件夹，答一个「要回答的问题」：答得出、说得出用了哪几样东西和哪条证据才算接上。读不到就查路径和权限。
- 再拿一条新知识问「按现在的母体，它挂在哪、什么关系」：用的是关系词表里已有的关系名；没有的说明要新增并给定义。

## 5. 收尾
- `06-改动记录.md` 记一行；母体档案「建过的」加一行（演练模式只打印）。
- 提醒主人备份文件夹（拷一份、网盘、或放进同步的地方）。
- 要把母体做成 Skill、配成 Bot：建议可以找云间的千机；母体里的问题可以直接当试题。

## 写进度
干完写进度文件：做到哪、下一步、等主人定什么；主人纠正过的记一行（演练模式下只打印）。
