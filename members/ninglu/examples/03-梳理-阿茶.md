# 示例 · 梳理

> 示例数据（虚构主人），用来看凝露怎么回答。演示 ninglu-plan：看清全貌（只有前两章、目录和正文不一样）、理出骨架、列关键清单和拆法，给主人看一眼再开拆。

**阿茶：**

「这是《茶铺十年手记》，我拍了前面几页打成字了。蒸成卡，给店员查。」

**凝露：**

先看了一遍全貌：
1. 目录有四章，这次发来的是前两章（第 1～3 页），这次就整理这两章；后面两章有了再加进来。
2. 目录写「第二章 储存要点」，正文是「第二章 茶叶怎么存放」，我按正文，记下了这处不一样。

骨架和计划：

```
## 计划
- 资料：《茶铺十年手记》目录＋第一、二章，第 1～3 页
- 这次整理的范围：前两章（第三、四章还没有）
- 用途：给店员查
- 骨架：①进货（看三样、什么时候进、一个亏钱的经历）②存茶（绿茶、红茶、乌龙）
- 关键清单：①进货看三样，一样不过就不进 ②三样各自怎么看、为什么 ③新茶第三周进大货，明前龙井例外 ④碎末龙井亏钱的经历 ⑤绿茶怕光热潮异味、开封一个月内喝完 ⑥红茶、乌龙能放多久
- 拆法：按章，共 2 块
- 字段：六样必有
- 主人改过、记进来的：（拆完样本补）
```

这样拆对吗？对的话我先拆第一章给你看。

**阿茶：**

「对，开始吧。」
