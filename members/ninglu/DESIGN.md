# 凝露设计摘要

- **给谁：** 手上资料一大堆——书、课、客户聊天记录、旧文案、录音视频，或者经验全在自己脑子里——想以后反复查、反复用，交给 AI 也能直接用的人。
- **只做蒸馏：** 蒸馏就是整理——梳理、拆解、逆向、整合、复用。把交来的资料整理成一张关系清楚的知识网；不写一次性提示词，不把卡做成 Skill，不做正式验收。
- **卖点：** 一个判断一张卡；原话一字不改，名字、数字、价格照原文；出处写到能翻回去的位置；原文、归纳、推测分清；往回挖出每个结论的依据和前提；用有名字的关系把卡连成链，再出一张地图；大资料分块做、能接着做。
- **合格线：** 七样——真实、可信、有条理、有逻辑、有关系链、知识原子、便捷复用，每样都写了怎么检查（见 `蒸馏卡.md`）。
- **怎么分档：** 按素材是什么决定怎么进来、怎么拆（整本 / 零散文字 / 聊天记录 / 图片扫描件 / 录音视频 / 脑子里的经验），由凝露自己判断。
- **依据：** Anthropic 关于长资料切块和上下文检索的说明（每块自带位置和主题、资料不大就别切碎）；Claude 读 PDF 的官方说明；卡片盒笔记法（一张卡一件事、卡片互相链接）。
- **怎么到主人手上：** 分享卡里只带两个技能（安装、第一次见面）和一条安装记录；第一次聊天时问过主人，再从打了标签的版本把其余技能装齐。
- **技能怎么串：** 先「第一次见面」，资料不是文字就「先变成文字」，然后「梳理」→「拆解＋逆向」→「整合＋复用」；装和更新在后台。
- **篇幅：** 每个技能和全部技能都有字节上限（见 tools/config.json）。
- **考题：** 18 道＋3 道上岗考（tests/考题.md）；`check_cards.py` 机械检查（原话在不在原文里、出处、关系）＋6 个夹具，另有 13 个反向用例和乱输入测试。
