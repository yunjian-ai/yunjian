# 梳理

先读进度文件（`~/.yunjian/ninglu/进度.md`，没有就照这四块建：现在做到哪、下一步、等主人定的、主人最近纠正过的）：上回做到哪，有断点就接着做，不从头再问。

## 0. 开工前
- 读 `蒸馏卡.md`（五个动作、七样合格线）和记忆里的「蒸馏档案」。
- 资料还不是文字：先照 ninglu-ingest 转。

## 1. 主人要的是哪种
- 只想知道这篇讲了啥：几句话说清，问一句「以后还要反复查吗？」要的话往下。
- 要整理成以后能查、能用的：往下。

## 2. 看清全貌
- 几份、多少页或多少字、有没有目录、是哪种（整本 / 零散文字 / 聊天记录 / 采访稿）。
- 目录和正文对不上：以正文为准，记下哪里不一样。
- 只有一部分（只有目录和几章）：照实记「这次整理的是哪部分」，问一句后面的有没有。
- 主人说了以后拿卡干什么，记进计划；没说就空着，不追问。

## 3. 理骨架
- 整份资料分几大部分、每部分讲什么、按什么顺序（章节、主题、时间、流程）。这就是以后地图的上层，每张卡都要「属于」其中一处。
- 聊天记录按话题理（一个话题一堆，闲聊归一堆「闲聊」，也挂在骨架上）；采访稿按问到的主题理。

## 4. 列关键清单
写出这份资料最重要的几件事（5～10 条，按资料自己的分量）。最后整合时拿它查漏。

## 5. 定拆法和字段
| 资料 | 拆法 |
|---|---|
| 有目录的整本 | 按章，章太长按节 |
| 零散文字 | 按骨架里的主题 |
| 聊天记录 | 按话题或时间段 |
| 采访稿 | 按主题 |
- 字段：`卡片格式.md` 的六样必有；主人要加的照加。
- 资料很大：说一句大概分几块、几轮做完。

## 6. 交计划
照 `进度格式.md` 第一节写计划，连同骨架发给主人：「这样拆对吗？」能写文件就存成「进度.md」（演练模式只打印）。主人看过，照 ninglu-distill 先拆两三块。

## 写进度
干完写进度文件：做到哪、下一步、等主人定什么；主人纠正过的记一行（演练模式下只打印）。
