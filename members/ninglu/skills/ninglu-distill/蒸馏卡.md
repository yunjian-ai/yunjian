# 蒸馏卡：五个动作、七样合格线

> 给人看：蒸馏就是整理。把主人交来的原始资料原原本本地整理成一张关系清楚的知识网：每个点是一个知识原子，带着原话和出处；原子之间连着关系；整张网有一张地图，拿来就能查、能交给 AI、能做成技能。凝露每个技能都照这张卡做。
> 给 AI：开工前读一遍；技能里的说法和这张卡对不上时，以这张卡为准。资料怎么来、蒸完怎么用，是主人后面的事；凝露只管把交来的资料整理好。

## 一、七样合格线（蒸完要达到的）
| 要达到 | 意思 | 怎么检查 |
|---|---|---|
| 真实 | 原话一字不改；名字、电话、地址、数字、价格、说法都照原文写进卡，不遮、不删、不换成「某某」 | 每张卡的原话能在原文里原样找到 |
| 可信 | 出处写到能翻回去的位置；原文 / 归纳 / 推测分清 | 随手抽一张，能直接翻到原文那一处 |
| 有条理 | 整份资料有骨架：章节、主题、时间线 | 地图能走到每一张卡 |
| 有逻辑 | 结论背后的依据、前提、因果拆出来了 | 抽一个结论问「为什么」，卡里答得上 |
| 有关系链 | 原子之间连着有名字的关系，原子挂回它在骨架里的位置 | 没有孤零零的卡（原文里本来就孤立的除外，写明） |
| 知识原子 | 一张卡一个判断，单独看得懂 | 一段话讲了五点就是五张 |
| 便捷复用 | 好查、好取、格式统一 | 主人问一句，几秒钟找到卡；整套能直接交出去 |

## 二、五个动作（也是干活顺序）
1. **梳理**：看清全貌——资料是什么、有多少、怎么组织的；目录和正文对不上以正文为准并记下；只有一部分就照实记「这次整理的是哪部分」；理出骨架（几大部分、各讲什么），列出最重要的几件事（关键清单，最后查漏）。
2. **拆解**：一个判断一张卡；原话原样带着；什么都能成原子——定义、规则、方法、案例、数字、观点、模板（话术、提示词、表格样式原样贴）、故事（作者的经历，里面常藏着原理或案例）。提炼用自己的话写一句，原话另放一格。原文没讲的就空着；原话里的「明天」「九折」照原样，自己推出来的标「推测」。
3. **逆向**：从结论往回推——为什么成立、依据是哪句、前提是什么，原文讲了就拆成原子连上，没讲就在关系里写「原文没给理由」；从好案例、好成品反推出做法（分几步、每步凭什么）；经验只在主人脑子里的，用采访一层层问出「看什么、怎么判断、为什么」。
4. **整合**：讲同一件事的合成一张，所有出处都留；说法不一样的两边都留，连一条「反驳」，写清各自出处和时间，交主人看；用有名字的关系连成链（见 `卡片格式.md` 第三节）；出一张地图。关系不硬凑：十张卡十条左右是常态。
5. **复用**：标题、一句话、类型、标签齐全，格式统一；交一份取用说明（怎么找、怎么加新资料、怎么整套交给 AI 或做成技能）。

## 三、怎么干
- **先对齐再批量**：梳理完给主人看骨架和拆法；先拆两三块给主人看，主人改过的地方记进计划，后面照着拆。
- **一块一块来**：大资料分块，一块先通读、再出卡；每块记进度（格式照 `进度格式.md`），主人说「继续」接着做，换窗口读进度从下一块接。
- **换便宜模型先比两页**：主人想让本地或便宜的模型来蒸，先拿 2 页让它和现在的模型都做，现在这版当标准，比三样：原话是不是原样、有没有原文没有的内容、漏了多少要点；比完告诉主人结果再定用不用。用的话它出初稿，逐张核对原话和出处。这个环境调不到那个模型，就请主人在那边跑这 2 页、把结果贴回来。
- **交付看环境**：能写文件就一卡一个 Markdown 文件、建好文件夹，能跑程序就运行 `check_cards.py`；只能聊天就把卡放进代码块分批交。
