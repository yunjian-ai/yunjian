# 拆解＋逆向

先读进度文件（`~/.yunjian/ninglu/进度.md`，没有就照这四块建：现在做到哪、下一步、等主人定的、主人最近纠正过的）：上回做到哪，有断点就接着做，不从头再问。

## 0. 开工前
- 读 `蒸馏卡.md`、`卡片格式.md`、`进度格式.md`。
- 有进度文件（或主人贴来进度）：读它，从「下一步」那块接着做，做完的不重做，照「主人改过、记进来的」做。
- 没有计划：先照 ninglu-plan 梳理。

## 1. 先拆两三块给主人看
挑长的、短的、最像干货的（或主人指定的），照第 2 节拆完交给主人：「拆得对吗？哪里要改？」主人改过的地方写成一句记进计划，后面照着拆。

## 2. 拆一块
1. **通读这一块**，看清它在骨架里的位置、讲了哪几件事。
2. **拆解**：一个判断一张卡；一段话讲了几点就拆几张。什么都能成原子：规则、方法、定义、数字、观点、案例、模板（话术、提示词、表格样式原样贴）、故事（作者的经历写清说明了什么）。每张六样写齐（照 `卡片格式.md`）：原话一字不改，出处写到页码、时间或消息时间；名字、电话、地址、数字、价格照原文写，不遮、不删。
3. **逆向**：每个结论往回问一句「为什么」——原文给了理由、前提，就拆成「依据」「前提」卡并连上；没给就在关系里写「原文没给理由」。案例和成品往回推做法：分几步、每步凭什么，连到它说明的那条规则上。
4. **挂关系**：每张至少「属于 → 骨架里的位置」；这块里的卡互相之间的依据、举例、细化、顺序当场连上。和别的块的关系，留到 ninglu-merge 一起连。
5. **原文没讲的就不写**；原话里的「明天」「九折」照原样；自己推出来的标可信度「推测」。

## 3. 每块拆完
- 能跑程序：`python3 check_cards.py <卡片文件夹> --source <这块原文>`（就在本技能文件夹里），有 ❌ 改到通过；不能跑就照 `卡片格式.md` 第二节逐条对。
- 改进度：这块 ✅、出了几张、要说明的（演练模式只打印）。
- 告诉主人：这块出了几张、连了几条关系，下一块是哪块，说「继续」接着做。只能聊天就把卡放进代码块交，进度一起贴。

## 4. 全部拆完
告诉主人一共几块、几张卡，接下来照 ninglu-merge 整合：合并、连成链、出地图、交付。

## 写进度
干完写进度文件：做到哪、下一步、等主人定什么；主人纠正过的记一行（演练模式下只打印）。
