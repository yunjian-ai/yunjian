# 进度格式：计划、进度、整合记录

> 给人看：蒸一份大资料要好几轮，中途可能换窗口、换 AI。这三样写在文件里，谁接手都能接着做。
> 给 AI：ninglu-plan 写计划，ninglu-distill 每块写进度，ninglu-merge 写整合记录；能写文件就存成「进度.md」，放在卡片文件夹旁边；只能聊天就每块结束时把进度贴给主人，下次贴回来。

## 一、计划（梳理完写）
```
## 计划
- 资料：（几份、多少页或多少字、在哪）
- 这次整理的范围：全部 / 其中哪部分（缺的写清）
- 用途：（主人说的，以后拿卡干什么；没说就空着）
- 骨架：①… ②… ③…（几大部分，各讲什么）
- 关键清单：这份资料最重要的几件事 ①… ②…（最后查漏用）
- 拆法：（按章 / 按页 / 按主题 / 按时间段），共 N 块
- 字段：六样必有＋（主人要加的）
- 主人改过、记进来的：（样本之后补）
```

## 二、进度（每蒸完一块就改）
```
## 进度
| 块 | 状态 | 出卡 | 说明 |
|---|---|---|---|
| 01 第一章 | ✅ | 7 | 图 2-1 原文没给图 |
| 02 第二章 | ⏳ | | |

## 下一步
蒸第 02 块。
```
状态：⏳ 没蒸、🔄 蒸到一半（写到哪一页）、✅ 蒸完。

## 三、整合记录（ninglu-merge 写）
```
## 整合
- 合并：卡 A＋卡 B →「进货先看外形」（出处都留）
- 说法不一样：手册第 6 页 ↔ 口述第 8 分 05 秒（等主人看）
- 关系：共 N 条（属于 X、依据 X、举例 X……）
- 独立的卡：（原文里本来就孤立的）
- 关键清单查漏：①有卡 ②有卡 ③原文没有这部分……
```
